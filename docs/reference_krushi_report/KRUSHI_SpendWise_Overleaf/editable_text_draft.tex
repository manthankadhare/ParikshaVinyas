INTRODUCTION\\ 

\smallskip

\smallskip
1.1 Background\\ 

\smallskip
Software testing is an important part of the Software Development Life Cycle (SDLC). It\\ 
is the process of evaluating a software application to identify defects and verify whether it\\ 
meets the specified requirements. Software testing helps improve software quality, reliability,\\ 
usability, and correctness by detecting problems and verifying application behavior under\\ 
different conditions.\\ 
SpendWise is a personal finance management application that provides features for man-\\ 
aging income, expenses, budgets, and financial transactions. Since financial information\\ 
must be recorded, processed, and displayed accurately, systematic testing is necessary to\\ 
verify input validation, transaction management, budget operations, balance calculations,\\ 
and interactions between different application modules.\\ 
This project focuses on Software Testing and Quality Assurance (STQA) of the SpendWise\\ 
application. Manual testing, selected automation tests, and AI-assisted testing techniques\\ 
are used to evaluate application functionality, identify defects, record test results, and assess\\ 
the overall quality of the application.\\ 

\smallskip

\smallskip
1.2 Problem Statement\\ 

\smallskip
The objective of this project is to evaluate the functional correctness and reliability of the\\ 
SpendWise personal finance management application using manual, automation, and AI-\\ 
assisted testing techniques. The testing activities focus on the application’s major func-\\ 
tionalities, including login, registration, income and expense management, budget planning,\\ 
transaction history, reports, profile settings, and logout.\\ 
The testing process aims to identify functional defects, input validation issues, incorrect\\ 
transaction handling, calculation errors, and unexpected application behavior. Test cases\\ 
are designed and executed using different input conditions, and the observed results are\\ 
compared with the expected results. The identified defects are documented through test\\ 
results and defect reports to assess the application’s quality and highlight areas requiring\\ 
improvement.\\

1.3 Objectives\\ 

\smallskip
The main objectives of the SpendWise STQA project are:\\ 

\smallskip

\smallskip
• To understand the functional requirements and major modules of the SpendWise ap-\\ 
plication from a testing perspective.\\ 

\smallskip
• To design and execute manual test cases for the application’s key functionalities.\\ 

\smallskip
• To perform functional testing, boundary value analysis, equivalence partitioning, and\\ 
other relevant testing techniques.\\ 

\smallskip
• To automate selected test cases using Selenium WebDriver and pytest.\\ 

\smallskip
• To identify, record, and document defects discovered during testing.\\ 

\smallskip
• To evaluate input validation for invalid, empty, zero, negative, and excessively large\\ 
input values.\\ 

\smallskip
• To compare manual testing observations with automation testing results.\\ 

\smallskip
• To evaluate the application’s behavior across different modules and input conditions.\\ 

\smallskip
• To identify areas requiring improvement based on the testing results.\\ 

\smallskip

\smallskip
1.4 Scope of the Project\\ 

\smallskip
The scope of this project is limited to testing the main functionalities of the SpendWise\\ 
personal finance management application. Manual testing, selected Selenium automation\\ 
tests, and AI-assisted test design are used to examine the application’s behavior under\\ 
different input conditions and user operations.\\ 
The testing covers important modules such as user login, registration, income and expense\\ 
management, budget planning, transaction handling, dashboard, reports, profile settings,\\ 
logout, and account deletion. Each module is examined through relevant test scenarios to\\ 
verify whether its functions work as expected. The project also includes test case execution,\\ 
result analysis, defect identification, and documentation to provide an overall assessment of\\ 
the application’s quality and reliability.\\

6.1 Introduction to AI in Software Testing\\ 

\smallskip
Artificial Intelligence (AI) is increasingly being used in software testing to support test case\\ 
generation, test scenario analysis, and identification of potential application risks. AI tools\\ 
can help testers understand application requirements, suggest test scenarios, and identify\\ 
areas that may require additional testing.\\ 
In this project, AI tools were used to support the testing of the existing SpendWise personal\\ 
finance management application. The tools were used to generate test scenarios, review\\ 
possible test cases, and identify potential risks and defects.\\ 
The test cases suggested by AI were reviewed and selected based on the functionality of\\ 
the SpendWise application. The selected scenarios were then checked against the actual\\ 
application. AI was used as a supporting tool, while the final validation and test results\\ 
were based on the observed application behaviour.\\
